Nova PDF portable mode

While this file sits next to novapdf.exe, Nova PDF keeps its settings, log files, crash-recovery
autosaves and new digital IDs in the Nova PDFData folder beside it, and writes nothing to
%APPDATA% or %LOCALAPPDATA%. Copy the whole folder to move Nova PDF with its settings.

Delete this file to use the normal per-user folders (%APPDATA%\Nova PDF and
%LOCALAPPDATA%\Nova PDF) instead. If Nova PDFData can't be written (for example on a read-only
drive), Nova PDF says so and uses the per-user folders instead.
